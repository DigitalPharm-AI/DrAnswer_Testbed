# 암종별 Agentic AI 트리거 기준

## 신장암

| Agent | Agentic AI 트리거 기준 |
|---|---|
| 부작용 감지 Agent | 환자가 약 또는 부작용과 관련된 질문을 입력하고, 메시지에서 부작용 관련 내용이 감지될 때 트리거된다. 예: “속이 메스꺼운데 약 때문일까?” |
| PRO-CTCAE 문항 응답 / 부작용 기록 Agent | 부작용 가능성이 감지되어 PRO-CTCAE 문항 응답이 시작되고, `/chat/ae-response`로 질문별 응답이 저장될 때 트리거된다. 모든 문항 응답이 완료되면 부작용 기록 완료로 전환한다. |
| 복약 알림 안전 확인 Agent | PRO-CTCAE 응답 완료 후 부작용 기록이 생성되었고, 현재 복약 알림을 유지해도 안전한지 확인이 필요할 때 트리거된다. 환자에게 “알림 유지하기” 또는 “알림 모두 끄기” 선택을 유도한다. |
| 미복용 감지 Agent | 예정 복약 시간이 지났는데 복약 기록이 없을 때 시스템 이벤트로 트리거된다. 환자에게 현재 상태와 미복용 이유 입력을 요청한다. |
| 미복용 원인 분석 Agent | 미복용 알림 이후 환자가 채팅으로 미복용 사유를 입력할 때 트리거된다. 예: “속이 안 좋아서 못 먹었어”. 원인이 부작용과 관련될 가능성이 있으면 부작용 조회 및 PRO-CTCAE 흐름으로 연결한다. |
| 복약 완료 기록 Agent | 미복용 이후 멀티턴 메시지에서 복약 완료 보고가 감지될 때 트리거된다. 예: “아까 약 먹었어”. `mark_dose_taken`으로 복약 완료를 기록한다. |
| 일일 복약 패턴 분석 Agent | 하루 종료 후 복약 기록, 미복용 기록, 이전 패턴을 수집할 때 트리거된다. 미복용 패턴이 반복되면 알림 정책 변경 후보를 생성한다. |
| 알림 정책 변경 Agent | 복약 패턴 분석 결과 알림 정책 변경 후보가 생성되거나, 환자가 “아침 알림 더 자주 줘”처럼 알림 변경 의도를 입력할 때 트리거된다. 즉시 적용하지 않고 정책 확인 버튼 선택을 유도한다. |
| 멀티턴 대화 Agent | 환자가 일반 대화 또는 이전 맥락을 묻는 채팅을 입력할 때 트리거된다. 최근 대화 맥락을 기반으로 자연어 응답을 생성한다. 예: “아까 뭔말했더라”. |
| 부종 주의 단계 감지 Agent | 인바디 측정값이 신장암 부종 주의 기준에 해당할 때 트리거된다. 기준: `0.39 <= 측정값 <= 0.4`. 환자에게 부종 관련 알림과 식이 조절 제안을 제공한다. |
| 부종 위험 단계 감지 Agent | 인바디 측정값이 신장암 부종 위험 기준을 초과할 때 트리거된다. 기준: `측정값 > 0.4`. 환자 알림과 함께 의료진 Web App으로 의료진 알림을 전송한다. |
| 인바디 미측정 감지 Agent | 최근 1주일 동안 인바디 측정 기록이 없을 때 시스템 이벤트로 트리거된다. 환자에게 인바디 측정을 유도한다. |
| 영양 성분 초과 섭취 감지 Agent | 식이 입력 기록에서 단백질, 나트륨, 칼로리, 지방 등 일일 섭취량이 환자별 cut off를 초과할 때 트리거된다. 환자에게 식이 조절 제안을 제공한다. |
| 식이 미입력 감지 Agent | 취침 전까지 입력되지 않은 식이 기록이 있을 때 시스템 이벤트로 트리거된다. 환자에게 식이 입력을 유도한다. |

## 공통점과 차이점

| 구분 | 내용 |
|---|---|
| 공통점 | 복약/부작용 관련 Agent는 신장암과 유방암이 동일하다. 공통 흐름은 부작용 감지, PRO-CTCAE 응답 저장, 부작용 기록 완료, 복약 알림 안전 확인, 미복용 감지, 미복용 사유 분석, 복약 완료 기록, 일일 패턴 분석, 알림 정책 변경, 멀티턴 대화 응답이다. |
| 신장암 차이점 | 인바디 측정값을 수치 기준으로 `부종 주의 단계`와 `부종 위험 단계`로 나눈다. 주의 단계는 환자 알림과 식이 조절 제안 중심이고, 위험 단계는 의료진 알림까지 연결한다. 식이는 단백질, 나트륨, 칼로리, 지방 초과를 중간~높음 위험도로 다룬다. |
| 유방암 차이점 | 인바디 부종 관리는 단순 수치 단계보다 증상 지속 기간을 중심으로 나눈다. 3일 미만은 다음날 재측정 유도, 3일 이상 지속은 의료진 알림 및 내원 판단으로 연결한다. 식이 초과는 낮은 위험도의 피드백 텍스트와 식이 조절 제안 중심으로 처리한다. |
