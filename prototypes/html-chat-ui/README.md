# 닥터앤서 HTML UI 프로토타입

현재 Jinja/HTMX 화면을 교체하지 않고 디자인과 상호작용을 검토하기 위한 독립형 정적 프로토타입입니다.

## 확인할 수 있는 항목

- HOME / Chat 화면 전환
- 기존 UI와 유사한 상단 시간 바, 회색 패널, 복약·영양·알림 구성
- 실행 중 1초마다 60분씩 진행하는 시뮬레이션 시간
- 복약 구분·시간 입력 없이 당뇨약, 고혈압약, 신장암 치료약, 유방암 치료약을 보여주는 오늘의 복약 목록
- 복약 종류 라벨과 4개 높이 이후 세로 스크롤되는 타임라인
- `text`, `selection_box`, `input_box`를 타입명 노출 없이 같은 메시지 구조로 표현한 채팅
- 날짜별 일반 구분선으로 이어지는 연속 대화 이력
- AI 답변별 좋아요 / 싫어요
- 선택 입력 피드백과 4,000자 카운터
- 채팅 메시지 전송 및 가상 AI 응답
- 데스크톱, 태블릿, 모바일 반응형 레이아웃

## 범위

- LOGS 화면은 포함하지 않습니다.
- Backend 및 AI Server로 실제 요청을 보내지 않습니다.
- `index.html`을 브라우저에서 직접 열어 확인할 수 있습니다.
